# 실제 브라우저 기능 확인

npm run dev로 시작하고 터미널에 표시된 주소를 엽니다. 아래 결과를 직접 확인하세요. jsdom 통과만으로 브라우저 레이아웃/IME 검증을 대신하지 않습니다.

## 브라우저 내장 검사와 반응형

1. 코드 따라가기 → 12개 검사 실행 → 전부 PASS.
2. 다시 실행 → 같은 결과, 기존 실습 작업/이력 유지.
3. 개발자 도구에서 콘솔 오류 확인.
4. 창을 약 390px로 줄이기 → 메뉴가 위로 이동, 패널이 한 열, 가로 페이지 넘침 없음.
5. Tab으로 메뉴/버튼/입력/편집기 이동 → 포커스 표시 확인.
6. Phase 1과 Phase 2를 오가도 상태가 유지되는지 확인.
7. 새로고침하면 모든 이력과 작업이 초기화되는지 확인.

이 문서는 재현할 절차이며, 각 항목이 실제 브라우저에서 실행됐다는 기록을 의미하지 않습니다.

## Node World

### 메인 이야기 · 실제 Patch 게이트

1. 첫 화면의 실제 DOM과 비어 있는 VDOM 자리에서 시작한다. DOM 읽기로 기존 VDOM이 생성되는지 확인한다.
2. 신규 VDOM의 말·속성·추가·삭제·교체·이동을 바꾸어도 실제 DOM은 그대로인지 확인한다.
3. Diff를 시작하고 노드 쌍이 비교 자리까지 걸어 나오는지, 같은 쌍은 유지·다른 쌍은 변경 명령으로 수집되는지 확인한다.
4. 자동 비교를 끝내도 실제 DOM이 바뀌지 않는지 확인한다. Patch 캐릭터는 비교 완료 전에는 누를 수 없어야 한다.
5. Patch 캐릭터를 누르면 변경 명령을 들고 DOM으로 걷고, 도착했을 때 실제 화면이 바뀌어야 한다. TEXT/PROPS/MOVE는 기존 DOM을 재사용하고 REPLACE는 대상만 새 DOM으로 교체해야 한다.
6. 새 초안을 만들면 적용된 VDOM이 기존 기준으로 바뀌어야 한다. State +3도 Patch 이전까지 화면은 그대로여야 한다.
7. 비교 재생 중이나 Patch 배달 중 처음으로 돌아가기를 누르면 지연된 동작이 다시 화면을 바꾸지 않아야 한다. 모션 감소·키보드 조작도 확인한다.

### 고급 관찰 · 완료 기록 재생

- 이전 VDOM·다음 VDOM·실제 DOM이 같은 비교 보드에 나타나는지 확인한다. 변경 노드와 유지 노드의 색과 설명이 구분되어야 한다.
- 비교 단계에서는 이전 DOM이 유지되고, 적용 버튼을 누르면 바뀐 부분만 갱신되어야 한다. 노드 선택 시 양쪽 VDOM과 대응 DOM 위치가 연결되어야 한다.
- 글자/속성 변경과 keyed 이동은 실제 DOM 객체를 재사용하고, 교체는 새 객체임을 표시해야 한다. 그대로 두기는 Patch 0개와 DOM 유지를 보여야 한다.
- 걸어가는 캐릭터는 팔다리 동작과 함께 이동하고, 제자리에 도착하면 걷기를 멈춰야 한다. 재생 속도를 느리게 바꾸면 입장·퇴장도 느려져야 한다.

- 말 바꾸기, 옷 갈아입기, 추가, 삭제, 친구 교체, 자리 바꾸기를 눌러 실제 DOM과 여섯 Patch 분류가 일치하는지 확인한다.
- 부모·자식이 가지로 연결된 하나의 트리인지 확인한다. 추가된 캐릭터는 화면 밖에서 자기 자리로 들어오고, 삭제된 캐릭터는 가지를 떠나 화면 밖으로 퇴장해야 한다.
- 친구 교체 시 이전 캐릭터의 퇴장과 새 캐릭터의 입장이 함께 보여야 한다. 말·옷 변경은 VDOM 버전 교대이며 실제 DOM은 재사용한다는 표시가 있어야 한다.
- 자리 바꾸기에서 같은 key의 얼굴이 이전 위치에서 다음 위치로 이동하는지 확인한다. 모션 감소 설정에서는 이동 애니메이션 없이 결과를 보여야 한다.
- State +3은 숫자 +3, Memo 값 +6, 렌더 횟수 +1을 표시해야 한다.
- 기록 선택과 단계 재생은 실제 DOM을 변경하지 않아야 한다. Undo/Redo는 Node World의 DOM 실험 상태만 복원해야 한다.
- 최신 다음 VDOM 노드를 선택하면 대응 DOM을 강조하고, 메뉴를 이동하면 강조가 사라지는지 확인한다.
- 390px 화면에서 컨트롤이 줄바꿈되고 큰 트리는 무대 안에서 스크롤되는지, Tab으로 노드와 재생 버튼을 조작할 수 있는지 확인한다.

이번 구현의 실제 브라우저 관찰은 도구가 Windows의 현재 URL을 확인하지 못해 완료하지 못했다. 자동 검증과 별도로 위 시각·키보드 검증이 남아 있다.
